# 日语生活剧场

一个以联网词典为核心、保留本地练习进度的 5 分钟日语生活场景练习工具。

## 运行

建议在当前目录启动一个静态服务器（直接双击 `index.html` 只能预览界面，浏览器可能阻止本地词库加载）：

```powershell
py -m http.server 4173
```

然后打开 `http://localhost:4173`。

## AI 自由聊天（DeepSeek）

今日练习中可以切换到“AI 自由聊天”。AI 会围绕当前场景陪练，并返回日语回复、中文意思、平假名、罗马音和快捷回答。固定场景仍然可以完全离线使用。

本地测试时，在 PowerShell 中设置环境变量后启动项目：

```powershell
$env:DEEPSEEK_API_KEY = "你的密钥"
$env:DEEPSEEK_MODEL = "deepseek-v4-flash"
node server.js
```

密钥只放在服务端环境变量里，不要写进 `app.js`、GitHub 仓库或静态网页。GitHub Pages 只能托管静态文件，不能安全保存 DeepSeek 密钥；以后要让公开网址也能使用 AI，需要把 `server.js` 部署成一个后端接口，再通过 `window.NIHONGO_AI_ENDPOINT` 指向它。

## 当前版本

- 车站买票、问路与换乘、出租车沟通三个场景
- 文字对话、快捷回答、提示、假名/罗马音切换
- 系统日语朗读（如果 Windows 浏览器支持 SpeechSynthesis）
- 本地词典：内置 JMdict 常用词、约 27.4 万个全量日语词形、约 27.8 万条日中专业释义、常用旅行地名和中文学习词条；支持日语、中文、假名、片假名、罗马音搜索
- 联网补充：本地未命中时查询 Jotoba 专名/词条和中文维基词典，不再依赖北辞郎文本解析
- 词库构建：运行 `node scripts/build-dictionary.mjs` 可按固定版本重新生成常用 JMdict；`scripts/build-jmdict-extended.mjs` 可重新生成全量日语词形与读音索引
- 对话和词典句子中的带下划线词，可以点击查看中文意思
- 本地 localStorage 保存连续学习和复习表达
- 固定场景和已下载词库无需联网；扩展词库会在首次查到常用词库没有的内容时按需加载，联网 Jotoba 仍作为最后补充

## 手机正式使用（PWA）

推荐把整个 `Test1` 文件夹部署到一个 HTTPS 静态网址。手机第一次打开网址后，在浏览器菜单选择“添加到主屏幕”，之后即可像普通 app 一样启动。词典查询通过公开在线接口完成，断网时会明确提示无法查询。

手机端不再依赖电脑、局域网 IP 或 `server.js`。`server.js` 只用于本地开发和测试；PWA 的安装按钮会在浏览器允许安装时自动出现。

注意：PWA 的离线缓存和安装能力需要 HTTPS，开发阶段的 `localhost` 例外；直接双击 `index.html` 只能预览，不能完成安装。

## 手机访问

1. 电脑和手机连接同一个 Wi-Fi，或让电脑连接手机热点。
2. 在 `Test1` 目录启动局域网服务：

```powershell
node server.js
```

3. 终端会自动显示手机访问地址，例如 `http://172.20.10.4:4173/`。
4. 手机浏览器打开该地址。

如果 Windows 防火墙弹出提示，请允许 Node 在“专用网络”通信。手机访问时不要使用 `127.0.0.1`，那会指向手机自己。
